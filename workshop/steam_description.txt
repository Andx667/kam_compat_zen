[h1]KAM Compat ZEN[/h1]

[b]KAM Compat ZEN[/b] bridges [url=https://github.com/Tomcat-SG/KAM]KAT - Advanced Medical (KAM)[/url] into [url=https://github.com/zen-mod/ZEN]Zeus Enhanced (ZEN)[/url], adding right-click context menu actions for KAM's medical systems — all nested under a single "KAM" category in the Zeus menu.

[h1]Requirements[/h1]

[list]
[*] [url=https://github.com/CBATeam/CBA_A3]CBA_A3[/url]
[*] [url=https://github.com/acemod/ACE3]ACE3[/url]
[*] [url=https://github.com/Tomcat-SG/KAM]KAT - Advanced Medical (KAM)[/url]
[*] [url=https://github.com/zen-mod/ZEN]Zeus Enhanced (ZEN)[/url]
[/list]

[h1]Features[/h1]

[list]
[*] [b]Chemical[/b] — Create Gas Cloud (radius, gas type, sealable)
[*] [b]Circulation[/b] — Change Blood Type / Volume, Set Cardiac State
[*] [b]Misc[/b] — Enable / Disable AI Death Prevention
[*] [b]Breathing[/b] — Set Pneumothorax Severity
[*] [b]Airway[/b] — Manage Airway (obstruction / occlusion)
[/list]

Each module has its own CBA setting to hide its menu entry.
